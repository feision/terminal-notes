# terminal-notes

Terminal, PowerShell, and Kilo terminal stability notes for an English Windows system with Chinese text support.

## Documents

- `terminal-fix-readme.md` - short project-facing summary.
- `terminal-fix-postmortem.md` - incident and root-cause review.
- `terminal-fix-guide.md` - step-by-step configuration guide.

## Scope

This repository records the changes made to improve:

- Chinese text rendering.
- PowerShell UTF-8 behavior.
- Kilo run-script stability.
- Terminal noise and VT/ANSI control-sequence issues.
